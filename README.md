# Jumpstart Medical — Website

A redesigned, SEO-optimized, fully responsive static website for **Jumpstart Medical**,
a primary, urgent, and telemedicine care practice in Flushing, Queens, NY led by
Dr. Shalena Islam.

Content, colors, and services mirror the live practice (jumpstartmedical.care); the
layout and design are a fresh, modern rebuild.

## Structure

The site follows the practice's existing URL structure:

```
/                                         Home
/services/                                All services
/services/telemedicine-queens-ny/         Telemedicine
/services/urgent-care-clinic-queens-ny/   Urgent care
/services/weight-loss-in-flushing-ny/     Medical weight loss
/about-us/                                About Dr. Shalena Islam
/contact/                                 Contact + booking + map
/blogs/                                   Health Journal
/self-assessment/                         Self assessment
/jumpstart-academy/                       Patient education
/404.html                                 Not found
```

Plus `sitemap.xml`, `robots.txt`, and `site.webmanifest`.

## Tech

- Hand-authored static HTML/CSS/JS — no build step required to deploy.
- Pages are generated by `build.py` from shared templates (run `python3 build.py`
  after editing content, then commit the regenerated HTML).
- Portable **relative** links, so the site works at a domain root, on GitHub Pages
  project subpaths, Netlify, Vercel, etc.

## SEO

- Unique `<title>` + meta description, canonical URL per page.
- Open Graph + Twitter Card tags and a social share image (`assets/img/og-image.jpg`).
- JSON-LD structured data: `MedicalClinic`, `Physician`, `MedicalProcedure`,
  `MedicalWebPage`, `FAQPage`, `BreadcrumbList`, `ItemList`, `Blog`, `WebSite`.
- Semantic HTML5 landmarks, skip link, descriptive `alt` text, `aria` labels.
- Responsive WebP images with `srcset`/`sizes` + lazy loading, `sitemap.xml`,
  `robots.txt`, geo meta tags.

## Local preview

```bash
python3 -m http.server 8080
# visit http://localhost:8080
```

## Deploy to GitHub Pages

1. Push this branch (or merge to `main`).
2. Repo → **Settings → Pages** → Source: *Deploy from a branch* → pick the branch,
   folder `/ (root)` → Save.
3. Site publishes at `https://<owner>.github.io/jumpstartcare/`.

The included `.nojekyll` file ensures all assets are served as-is.
